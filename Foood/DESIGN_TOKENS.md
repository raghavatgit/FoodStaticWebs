# FoodStaticWebs Design Tokens and Grid Architecture

## Color Palette
* **Primary Coral:** `#ff6b6b` (Call to actions and reservation buttons)
* **Secondary Teal:** `#4ecdc4` (Feature cards and badges)
* **Warm Amber:** `#ff9f43` (Gradient accent)
* **Dark Charcoal:** `#2d3436` (Footer and high-contrast text)

## Responsive Grid
Uses CSS Grid `auto-fit` with dynamic `minmax(250px, 1fr)` columns to eliminate rigid media query breakpoints across mobile and desktop displays.
