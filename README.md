A curated collection of modern, responsive static landing pages and menus designed for restaurants, cafes, and food brands.

---

## Overview

FoodStaticWebs contains clean, production-ready website templates tailored for the food and hospitality industry. Each template emphasizes visual storytelling, photography layouts, interactive digital menus, and table reservation call-to-actions.

---

## Features

* **Responsive Layouts:** Mobile-optimized navigation, adaptive image grids, and fluid typography.
* **Interactive Menus:** Category-based menu filtering with clear dietary tags and pricing tables.
* **Fast Load Times:** Lightweight markup and optimized CSS with zero bloated dependencies.
* **Cross-Browser Compatible:** Tested across modern web browsers (Chrome, Firefox, Safari, Edge).

---

## Getting Started

Simply open any template folder (e.g. `Foood/`) and launch `index.html` in your favorite browser, or serve it using any local static file server.

```bash
# Clone the repository
git clone https://github.com/raghavatgit/FoodStaticWebs.git
cd FoodStaticWebs
```
